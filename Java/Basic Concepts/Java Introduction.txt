What do you mean by Platform Independent?
==========================================
- Platform independent means a program can run on different operating systems without changing or recompiling the source code. 
  The same program can run on Windows, Linux, or macOS."
- Example : If I write a Java program on Windows, I can run the same compiled file on Linux or macOS without modifying the code.

How is Java Platform Independent?
===================================
- Java is platform independent because the Java compiler converts source code into bytecode instead of machine code. 
  This bytecode can run on any operating system that has a Java Virtual Machine (JVM). 
  Since every platform has its own JVM, the same bytecode runs everywhere. That's why Java follows the principle 'Write Once, Run Anywhere (WORA).'
- Explain with Diagram : 
Java Source Code (.java)
          │
          ▼
      Java Compiler (javac)
          │
          ▼
      Bytecode (.class)
          │
          ▼
        JVM
          │
          ▼
Windows   Linux   macOS

 Is JVM Platform Dependent or Platform Independent?
======================================================
- Each operating system has its own JVM implementation.
- For example:
Windows uses Windows JVM
Linux uses Linux JVM
macOS uses macOS JVM
- Although the JVM implementation is different for each operating system, they all understand the same Java bytecode.
- JVM is platform dependent because each operating system requires its own JVM implementation. 
  However, the bytecode generated by Java is platform independent, so the same bytecode can run on any JVM.

If JVM is platform dependent, then how is Java platform independent?
=====================================================================
- The Java compiler generates platform-independent bytecode. Every operating system has its own platform-dependent JVM that understands this bytecode. 
  Since the bytecode remains the same and only the JVM changes, Java applications can run on different platforms without recompilation

=> What is static or dynamic programming language? 
==================================================
- A static programming language performs type checking at compile time. Variables must have a fixed data type before execution.
- A dynamic programming language performs type checking at runtime, and variable types can change during execution.
- Example: Static: Java, C, C++ || Dynamic: Python, JavaScript, Ruby
- Java is mainly a statically typed language, not a dynamically typed language.

=> How java is dynamic programming language ? 
==============================================
- Java is not a dynamically typed language, but it has dynamic features.
- These include:
1) Dynamic class loading
2) Runtime object creation
3) Dynamic memory allocation
4) Reflection API
- So, we can say, Java is statically typed, but it provides dynamic features like dynamic class loading and runtime memory allocation.

==============================================
Java does not require a preprocessor because:
- It does not use macros like C/C++.
- Features like packages, import statements, constants, and methods replace the need for preprocessing.
- This makes Java simpler, safer, and easier to maintain.
- Java doesn't require a preprocessor because it doesn't support macros. 
  It provides packages, imports, and constants instead, making the language more secure and easier to maintain

=> Why java does not support pointers ?
========================================
Java does not support pointers because pointers can:
  - Access memory directly
  - Cause memory corruption
  - Reduce security
  - Increase program complexity
Instead, Java uses references, which are safer.
- Java doesn't support pointers to improve security, prevent accidental memory access, and simplify programming. It uses object references instead of pointers.

=> What is call by reference and call by value ? 
================================================
1) Call by Value
- A copy of the variable is passed to the method.
- Changes inside the method do not affect the original variable.
- Example: Java
  int x = 10;
  change(x);
  x remains 10 after the method call.

2) Call by Reference
- The actual memory address is passed.
- Changes inside the method affect the original variable.
- Example:
  void change(int &x)

How Java works :  Java is always call by value.
For primitive data types, the actual value is copied. For objects, the reference is copied, not the object itself.
- Java is strictly call by value. For primitive types, the value is copied. For objects, a copy of the reference is passed, 
allowing object data to be modified, but the reference itself cannot be changed

=> Why java has good memory management as compared to C & C++ ?
================================================================
- Java provides automatic memory management through the Garbage Collector (GC).
Advantages:
  - Automatically removes unused objects
  - Prevents memory leaks
  - Prevents dangling pointers
  - No need for manual memory allocation and deallocation
- In C/C++, programmers use malloc/free or new/delete, which can lead to memory leaks if not managed correctly.
- Java has better memory management because it uses automatic garbage collection. 
  The JVM automatically frees unused memory, reducing memory leaks and eliminating the need for manual memory management.
